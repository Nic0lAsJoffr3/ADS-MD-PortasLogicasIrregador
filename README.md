Simulador de Portas Lógicas com Sistema de Irrigação Automática

Este projeto foi desenvolvido como trabalho acadêmico de faculdade e tem como objetivo simular o funcionamento de um sistema de irrigação automática utilizando **portas lógicas digitais**.

---

Sobre o Projeto

O sistema simula um ambiente agrícola onde decisões são tomadas com base em condições ambientais, como:

- Umidade do solo (seco ou molhado)
- Presença ou ausência de chuva
- Temperatura ambiente

Essas entradas são processadas por meio de **lógica booleana**, utilizando portas lógicas como:

- AND (E)
- OR (OU)
- NOT (NÃO)

Com base nessas condições, o sistema determina quando o irrigador automático deve ser ativado ou desativado.

---

## Objetivo

O objetivo principal do projeto é demonstrar, de forma prática, a aplicação de:

- Matemática Discreta
- Lógica Digital
- Sistemas de decisão automatizados

em um cenário simulado de automação.

---

## Como funciona

1. O usuário define as condições ambientais:
   - Solo seco/molhado
   - Chuva sim/não
   - Temperatura alta/baixa

2. O sistema processa essas entradas com portas lógicas

3. O resultado final determina:
   - Irrigação ligada
   - Irrigação desligada
